# 淡江大學官方網站 | Tamkang University Official Website

## 📋 專案概述

仿淡江大學官方首頁的完整網站專案，包含首頁與多個子頁面。採用現代化設計，提供優秀的使用者體驗與完善的響應式設計。

## ✨ 主要特色

### 1. **首頁 (index.html)**
- 🎨 精美的導覽列與功能選單
- 🎠 4張圖片的自動輪播 (Carousel)
- 📢 招生資訊卡片區（支援 hover 動畫）
- 🌍 學校特色宣傳區（AI + SDGs）
- 📱 完整的響應式設計

### 2. **招生資訊頁 (pages/admission.html)**
- 📝 詳細的招生方案說明
- 📋 常見問題 FAQ（可展開/收合）
- 📞 聯絡資訊表單
- 💾 下載簡章功能

### 3. **學術單位頁 (pages/department.html)**
- 🏫 各學院介紹卡片
- 🔬 研究重點與特色展示
- 📊 學術成就統計資訊
- 🎓 系所詳細列表

### 4. **行政單位頁 (pages/office.html)**
- 🏢 各處室服務介紹
- 📞 快速聯絡資訊
- 🔗 快速導航連結
- 🗺️ 校園地圖區（預留）

### 5. **認識本校頁 (pages/about.html)**
- 📜 校史發展時間軸
- 🎓 校訓與願景介紹
- 📊 校園統計數據
- ⭐ 學校特色亮點
- 🏆 近年榮譽成就

### 6. **獎助學金頁 (pages/scholarship.html)**
- 💰 80+項獎助學金方案
- 🔍 獎學金篩選功能
- 📋 申請流程說明
- ❓ 常見問題解答
- 📈 獎助統計資訊

## 🛠️ 技術棧

- **HTML5** - 語意化標籤結構
- **CSS3** - 現代化樣式，包含：
  - Flexbox & Grid 佈局
  - 漸層背景效果
  - 動畫與過場效果
  - Media Query 響應式設計
- **JavaScript (ES6+)** - 互動功能：
  - 輪播控制
  - 漢堡選單切換
  - FAQ 展開/收合
  - 回到頂端按鈕
  - 搜尋功能
- **Font Awesome 6.4.0** - Icon 圖示

## 🎨 設計系統

### 色彩方案
- **主色** - #D91E1F（淡江大學紅色）
- **輔助色** - #FDB913（金色）
- **深色文字** - #333
- **淺背景** - #f8f9fa

### 響應式斷點
- **桌面版** - 1024px 以上
- **平板版** - 768px - 1024px
- **手機版** - 480px - 768px
- **超小屏** - 480px 以下

### 字體
- 使用系統字體棧：Segoe UI, Tahoma, Geneva, Verdana
- 支援 Google Fonts（可擴展）

## 🚀 功能說明

### 導覽列功能
- ✅ 上方紅色功能列（Logo、學校名稱、快速連結）

- ✅ 招生卡片 hover 動畫

- ✅ 快速導航連結

### 資料模擬
- ✅ 招生資訊以 JavaScript 陣列模擬

## 💻 使用方式

### 本地開發
```bash
# 使用 Python 開啟本地伺服器
python -m http.server 8000

# 或使用 Node.js http-server
npx http-server

# 或使用 VS Code Live Server 擴充功能
# 右鍵點選 index.html → Open with Live Server
```
